# ImportNow UI refinement 9

This update includes:
- Removed the decorative eyebrow dots and the 01–06 side note in End-to-end imports.
- Increased navbar link/button typography and changed quote buttons to burgundy.
- Restyled the four hero proof/stat blocks in graduated burgundy shades.
- Added a burgundy background to the moving route ticker and aligned its label to the left.
- Centered and enlarged the End-to-end imports heading, with a dark blue container-port photo background.

Run locally:
1. `npm install`
