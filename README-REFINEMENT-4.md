# ImportNow — Refinement 4

## Changes
- Client Stories now uses a right-side single-card carousel with previous/next arrow controls. Pagination dots, numeric indicators and thumbnail selectors have been removed.
- The client review card places the client identity and star rating at the bottom. The included reviews and ratings are sample content and should be replaced with approved real client feedback before publishing.
- Furniture & Interiors now lists sofas, sectionals, dining tables, chairs, bedroom sets, office furniture and hotel fit-outs. Its background clip is a modern furniture showroom video.
- Electronics & Tech now lists LED screens and digital signage; its background clip features large LED display screens.
- Category videos remain absolutely positioned inside fixed-height, overflow-hidden cards, with poster-image fallback if a video cannot load.
- Existing navy / steel-blue / terracotta visual theme is retained.

## Run locally
```bash
npm install
npm run dev
```

The background videos load from Pexels and require an internet connection.
